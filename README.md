# GPU / VRAM / Cost Calculator

Compare GPU costs for running AI models locally. NVIDIA, AMD, and Apple Silicon.

## Quick start (local dev)

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build for production

```bash
npm run build
```

Outputs to `dist/`.

## Deploy

This project is ready to deploy to Vercel, Netlify, Cloudflare Pages,
or any static host. Just push to GitHub and import the repo.

## Stack

- Vite + React 18
- Tailwind CSS
- lucide-react (icons)
- HuggingFace API (model search)
